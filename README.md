# 墨页 · 本地小说写作软件

一款**纯本地、轻量、不联网**的小说写作桌面软件。基于 **Electron** 构建，所有稿件数据都存在你电脑上，不上传任何云端。

![墨页主界面](docs/screenshot.png)

**作者：峻峻尼 · 版本：v2.4.2 · 开源协议：MIT**

## 特性

- **桌面应用（Electron）**：自带 Chromium 渲染，文件读写走原生 `fs`，数据稳定落盘。
- **分卷 / 章节管理**：多作品、多分卷、多章节，支持拖拽排序，结构一目了然。
- **自动保存**：编辑即存（0.3~5s 可调），刷新、关机都不丢稿。
- **实时字数统计**：当前章节字数、全书总字数、今日码字目标与进度条。
- **写作计时（内置）**：底栏常驻显示本次时长与新增字数；含番茄钟（专注 25 分钟 / 休息 5 分钟，到点自动提醒）与「今日累计」码字时长、字数（按秒记录、换章与重开都保留）。
- **写作习惯可视化**：写作热力图 + 近 14 天码字柱状图。
- **资料栏**：大纲 / 人物 / 设定 / 灵感 四栏卡片化笔记，随写随查。
- **知识库（边写边查）**：资料栏新增「知识库」tab，同时聚合「本书资料」与外部 Markdown 文件夹。本书资料自动列出当前作品的**大纲、人物、设定、灵感**卡片；外部库可连接本地 Markdown 文件夹（如 **Obsidian 库**；腾讯 ima 等云端库可先把笔记导出为本地 Markdown 再连接）。搜索笔记名、点开即看，阅读内容在宽敞的专用抽屉中显示，写稿同时随手翻资料。仅本机读取，不联网。
- **素材卡片**：随手存梗、金句、设定碎片。
- **查找替换**：编辑器内全文查找、逐个 / 全部替换。
- **历史快照**：每 5 分钟自动留存一份快照（保留最近 30 个），可回退。
- **自动排版**：失焦自动排版当前章节（半角标点转全角、中英文间加空格、引号全角、每段首行空两格等），各项可单独开关。
- **专注模式**：F11 一键沉浸写作。
- **多种导出**：全书 / 本章的 TXT、Markdown（保留粗体 / 斜体 / 标题层级），以及全部作品合并导出；JSON 备份与恢复。
- **三种主题**：宣纸 / 极简 / 夜间，护眼克制。
- **插件系统（即插即用）**：内置「全文搜索」与「自动备份」两个扩展插件，把插件文件夹放到安装目录的 `plugins/` 即生效，无需重装。详见下方「插件系统」。

## 快速开始

### 一键安装（推荐）

1. 到 [Releases](../../releases) 下载 `moye-novel-setup.exe`。
2. 双击运行，按向导安装（默认装到当前用户 `AppData\Programs\墨页`，**无需管理员权限**）。
3. 安装完成后从**开始菜单 / 桌面快捷方式**启动即可，并自带卸载程序。

> 若被 Windows SmartScreen 拦截，点“更多信息”→“仍要运行”即可。本软件未做代码签名，属正常现象，不影响使用。

### 数据存放位置

- **优先**：程序所在目录的 `data/novels.json`（便携版 / 解压即用，整包拷到任意电脑、U 盘都能带着稿子走）。
- **兜底**：若该目录不可写（例如装到 `C:\Program Files`），自动改存到 `%APPDATA%\墨页\data\novels.json`（永远可写）。
- 想直接打开数据文件夹，可在「设置 → 数据位置」点「打开数据文件夹」。

## 插件系统

墨页以「**核心功能 + 可插拔插件**」的方式组织：保存、字数、计时、排版、导出等基础写作工具内置于软件本体；扩展能力做成可独立启停的插件。

- **内置插件**
  - **全文搜索**：跨所有章节检索关键字，支持「区分大小写」与「正则表达式」，结果一键跳转到对应章节。
  - **自动备份**：按节流自动把整库写入 `data/backups/`，可设置保留份数与最小间隔，并逐份恢复历史备份。
- **用户插件**：把插件目录放到「墨页」安装位置下的 `plugins\`（或 `%APPDATA%\墨页\plugins`），重启即加载，无需重装。在顶栏「插件」抽屉里勾选启用 / 停用。
- **插件 API**：插件事 via `window.MoyePlugins.register` 注册，通过宿主提供的 `ctx`（数据 / 持久化 / 导航 / UI / 事件 / 设置）访问软件能力，自带工具栏按钮与设置区扩展位。

## 从源码构建

环境要求：Node.js 18+。

```bash
npm install          # 安装 electron / electron-builder / jsdom
npm test             # 运行文件层真实单测 + 渲染端集成冒烟
npm run dist         # 先生成内置插件清单，再 electron-builder 打包出安装包
```

构建完成后安装包在 `dist-electron/moye-novel-setup-<版本>.exe`。

本地开发预览：`npm start`（以 Electron 开发模式启动）。

## 目录结构

```
墨页/
├─ src/                  # 前端源码（主进程加载的渲染页面）
│  ├─ index.html         # 界面骨架（含启动错误浮层）
│  ├─ css/style.css      # 三套主题样式
│  ├─ js/store.js        # 存储层（通过 electronAPI 调主进程 fs）
│  ├─ js/app.js          # 核心逻辑（含内置写作计时）
│  └─ js/plugins/        # 插件宿主 host.js 与内置插件目录
├─ main.js               # Electron 主进程（窗口 + IPC + 文件读写 + 插件发现）
├─ preload.js            # 预加载脚本（把受限 IPC 暴露给渲染层）
├─ lib/fsstore.js        # 纯 Node 文件存储层（主进程与测试共用）
├─ scripts/build-plugins-manifest.mjs  # 构建时生成内置插件清单
├─ resources/icons/      # 应用图标
├─ .github/workflows/    # GitHub Actions 自动构建 Release
├─ test/                 # 单测（真实 fs 持久化 + jsdom 渲染冒烟）
└─ package.json
```
