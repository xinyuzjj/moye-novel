为小说写作设计

从灵感捕捉到完稿导出，每一步都更顺手

📚

分卷 / 章节管理

多作品、多分卷、多章节；支持折叠展开、拖拽排序，每个分卷可独立添加章节。

💾

编辑即保存

0.3~5 秒可调自动保存，随时按 Ctrl+S 立即落盘并生成历史快照，刷新关机都不丢稿。

📊

以今天为主的统计

环形进度 + 今日已写 / 目标 + 近 14 天柱状图 + 码字热力图，把「今天」放在最显眼的位置。

🎧

专注模式

F11 一键沉浸，隐藏所有边栏与顶栏，底部 HUD 实时显示今日进度与当前章节字数。

👤

人物出场分析

自动扫描全书，提取有名有姓的出场角色并标记章节，点击标签一键跳转，误判可忽略。

📦

多种导出格式

全书 / 本章 TXT、Markdown，全部作品合并导出，JSON 备份与恢复，换机无忧。

数据在你自己电脑上

墨页不登录、不上传、不联网。所有稿件默认保存在程序目录的 data/novels.json，整包拷到 U 盘就能带走；若安装到系统目录不可写，自动落盘到 AppData，永远不怕丢稿。

  • 优先便携存储，exe 同级 data 目录
  • 不可写时自动切换至 AppData\墨页\data
  • 原子写入 + 历史快照，防止写到一半损坏

插件扩展，即插即用

核心写作功能内置于软件本体，扩展能力做成可独立启停的插件

🔍

全文搜索

跨所有章节检索关键字，支持区分大小写与正则表达式，结果一键跳转。

🛡️

自动备份

按节流把整库写入 data/backups/，可设置保留份数与最小间隔，并逐份恢复。

🎹

打字音效

实时合成 6 种按键音色，机械键盘、老式打字机、木鱼、雨滴……无需音频文件。

把插件文件夹放到安装目录的 plugins\ 下，重启即加载，无需重装软件。
